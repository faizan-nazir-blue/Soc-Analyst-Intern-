# 🛡️ Task 02 – SOC Analyst Role Analysis

> A research-based task focused on understanding the responsibilities, skills, tools, certifications, and career path of a Security Operations Center (SOC) Analyst.

---

## 📖 About the Project

This project explores the role of a **Security Operations Center (SOC) Analyst**, the first line of defense against cyber threats. It covers the analyst's daily responsibilities, essential technical knowledge, commonly used security tools, industry certifications, and future career opportunities.

The goal of this task is to build a strong foundation for a career in **Blue Team Cybersecurity**.

---

## 🎯 Learning Objectives

- Understand what a SOC Analyst does.
- Learn the responsibilities within a Security Operations Center.
- Explore the technical and soft skills required.
- Become familiar with commonly used SOC tools.
- Discover certifications that help build a cybersecurity career.
- Understand future career growth and industry challenges.

---

## 📚 Topics Included

- Introduction to SOC Analyst
- Role & Responsibilities
- Technical Skills
- Soft Skills
- Security Tools
- Industry Certifications
- Career Roadmap
- Challenges in SOC Operations

## 🚀 Key Takeaways

- SOC Analysts continuously monitor security events.
- SIEM platforms are essential for threat detection.
- Networking and operating system knowledge form the foundation of SOC operations.
- Incident response requires both technical and analytical skills.
- Continuous learning is necessary to keep up with evolving cyber threats.
