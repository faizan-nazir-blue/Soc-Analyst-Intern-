# 🔐 Task 03 – Strong Password Exercise

> A cybersecurity exercise focused on understanding the difference between weak and strong passwords by creating examples and learning password security best practices.

---

## 📖 About the Project

This task demonstrates the importance of creating secure passwords by comparing **10 weak passwords** with **10 strong passwords**.

The objective is to understand what makes a password vulnerable to attacks such as brute-force, dictionary, and credential stuffing attacks, while learning the characteristics of strong authentication credentials.

---

## 🎯 Learning Objectives

- Understand the characteristics of weak passwords.
- Learn how strong passwords improve account security.
- Compare weak and strong password examples.
- Explore common password attacks.
- Follow password security best practices.

---

## 📚 Topics Covered

- Introduction to Password Security
- Weak Password Examples
- Strong Password Examples
- Password Strength Comparison
- Common Password Attacks
- Password Security Best Practices

---

## 🛠️ Concepts Covered

| Concept | Description |
|---------|-------------|
| Weak Passwords | Easy to guess and vulnerable to attacks |
| Strong Passwords | Long, complex, and difficult to crack |
| Brute Force Attack | Attempts every possible password combination |
| Dictionary Attack | Uses common words and leaked passwords |
| Credential Stuffing | Reuses stolen usernames and passwords |
| Password Complexity | Combination of uppercase, lowercase, numbers, and special characters |

---

## 📄 Exercise Contents

This task includes:

- ✅ 10 Strong Passwords

---

## 🚀 Key Takeaways

- Weak passwords are one of the most common causes of account compromise.
- Longer passwords are significantly harder to crack.
- Passwords should never contain personal information.
- Every online account should have a unique password.
- Password managers help generate and securely store complex passwords.
- Multi-Factor Authentication (MFA) adds an extra layer of security.
